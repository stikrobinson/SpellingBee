# SpellingBee

Aplicacion web simple para practicar spelling bee usando solo HTML, CSS y JavaScript.

## Uso

1. Abre `index.html` en un navegador compatible.
2. Pulsa `Nueva palabra` para cambiar el reto.
3. Pulsa `Escuchar palabra` para oir la pronunciacion.
4. Pulsa `Deletrear con voz` y di la palabra o las letras en voz alta.

## Nota

La captura de voz usa la Web Speech API, por lo que funciona mejor en navegadores basados en Chromium.
